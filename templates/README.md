# 项目可选模板

本项目用于建立可复用的书籍排版与编译基础，并在模板库中存放可独立选择的写作框架与排版方案。作者自行组织内容，也可选用这里的写作框架辅助构建全书。

## 写作框架

- [李星野书籍写作模板](写作框架/李星野书籍写作模板.md)：通过研究与写作形成、检验并传播理论。包含前言、六章加附录、按需要设置的公理／定理／推论、全书连接规则及验收要求。单个文件即可交给AI使用。

## 排版与编译

基础 LaTeX 工程位于 `../book/`，编译入口位于 `../scripts/build.ps1`。当前写作框架与排版工程分别维护；后续可以讨论更具体的映射和其他排版方案。

本目录仅存放当前可用的模板；研究资料与历史稿不随仓库保留。
