# 项目可选模板

本项目用于建立可复用的书籍排版与编译基础，并在模板库中存放可独立选择的写作框架与排版方案。作者自行组织内容，也可选用这里的写作框架辅助构建全书。

## 李新野

- **逻辑框架：**[李新野书籍写作模板](李新野/逻辑框架/李新野书籍写作模板.md)。通过研究与写作形成、检验并传播理论，包含全书组织、推导连接及验收要求。单个文件即可交给AI使用。
- **结构框架：**[书籍 LaTeX 结构模板](李新野/结构框架/README.md)。完整预留标题页、作者简介、目录、前言、正文、结语、附录，以及可选的版权说明和献词。可独立复制，部件按需启用。

## 排版与编译

`../book/` 是当前项目源稿，`李新野/结构框架/` 是供新项目复制的完整结构模板，编译入口位于 `../scripts/build.ps1`。同一来源的逻辑框架与结构框架放在一起，但可以分别选择，模板不会自动覆盖已有稿件。

本目录仅存放当前可用的模板；研究资料与历史稿不随仓库保留。
