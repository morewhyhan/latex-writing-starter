# 书籍 LaTeX 结构模板

完整的中文书籍排版工程，可独立复制到新项目。它负责页面与书籍部件的组织，不规定写作方法、章节数量或论证顺序。

默认顺序：标题页 → 版权说明（可选）→ 献词（可选）→ 作者简介（可选）→ 自动目录 → 前言（可选）→ 正文 → 结语（可选）→ 附录（可选）。

## 使用

1. 新项目中，将本目录的 `main.tex`、`config.tex`、`style.tex` 和整个 `content/` 复制到 `book/`。已有稿件时先比较差异，不覆盖正文。
2. 在 `config.tex` 填写书名、作者、日期和版本，并启用需要的部件。标题页、目录默认开启，其余可选部分默认关闭，避免空白稿产生空标题。
3. 在相应内容文件中写文字，正文自行添加章、节。目录从这些标题自动生成，作者简介等文字不会自动生成。
4. 在本仓库的 `book/` 使用时，按根目录的编译入口运行；独立使用时，在本模板目录执行 `latexmk -xelatex main.tex`。

需要 XeLaTeX、latexmk、ctex 及相应宏包。不随模板安装工具。

## 文件分工

| 文件 | 作用 |
|---|---|
| `main.tex` | 组合书籍部件，控制编号与目录 |
| `config.tex` | 书籍信息与部件开关 |
| `style.tex` | 页面尺寸、字号配套样式、命题环境与链接 |
| `content/title.tex` | 根据配置生成标题页 |
| `content/copyright.tex` | 自行填写版权或传播说明，不预设许可 |
| `content/dedication.tex` | 献词文字 |
| `content/author.tex` | 作者简介，可自行插入照片 |
| `content/preface.tex` | 前言文字 |
| `content/chapters.tex` | 正文，自行设置章节或引入独立章节文件 |
| `content/closing.tex` | 结语文字 |
| `content/appendix.tex` | 附录，自行添加附录章标题 |

作者简介、前言、结语启用后自动生成不编号标题并进入目录，内容文件只写正文，不重复添加标题。献词与版权说明独立分页。附录启用后使用附录编号，章标题由作者自己添加。

本目录是可复用模板，`book/` 是当前项目源稿，两者不自动同步。同一来源的逻辑框架存放在相邻目录：[李新野书籍写作模板](../逻辑框架/李新野书籍写作模板.md)。两者可以独立选择。本结构框架是参考原书部件后整理的预配置工程，不是原书版式的逐项复刻。
